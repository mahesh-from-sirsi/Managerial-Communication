# VTU MBA Managerial Communication Learning Portal

Static GitHub Pages site for VTU MBA Semester I, course 3MBA106, Scheme 2026.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `managerial-communication`).
2. Extract this ZIP and upload **all contents** of the `managerial-communication-portal` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in Settings → Pages.

`index.html` is at the repository root and is the homepage.

## Important syllabus alignment notes
- Current supplied syllabus: Scheme 2026, course code 3MBA106, five modules, 42 pedagogy hours.
- Module 3 supplement adds CV, group discussion, interview and technology-enabled communication missing from the supplied Module 3 notes.
- Module 4 supplement adds advanced business presentations/visual aids and negotiation processes/strategies, missing from the older 2024–25-based Module 4 notes.
- Supplied Module 5 PDF is Management & Organisational Behaviour (MBA101) material. It is not included as Managerial Communication content. A syllabus-aligned replacement Module 5 is provided.
- Historical question papers linked are for older 20MBA16 schemes. They are practice resources, not predictions for 3MBA106.
